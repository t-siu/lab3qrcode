1. What challenges did you face when refactoring your code to use Bootstrap?
The most challenging part of using Bootstrap was replacing my CSS with Bootstrap while keeping the layout consistent and responsive. It was also time consuming having to research the right commands to use since this is my first time using Bootstrap.

2. How did using Bootstrap utility classes and components simplify your styling process?
Bootstrap made styling easier because it already had options that was already made. This saved me time because I didn't have to write as much code.

3. In what scenarios might you choose not to use Bootstrap and write custom CSS instead?
I would use CSS when I need unique designs, special effects, or more control over styling.
